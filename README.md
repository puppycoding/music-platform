# Music Platform

A music discovery platform for Thai artists.

## Project Goals

- Browse Thai artists and their songs.
- Explore albums and music collections.
- Search and discover music.
- Organize music metadata for future features.

## Data Source

The project uses `music-catalog.json` as its initial music catalog.

The catalog contains artist, album, and song metadata. Streaming availability and playback rights must be verified separately.

## Planned Technology

- Frontend: React, TypeScript, Vite
- Backend: Python, FastAPI
- Database: PostgreSQL

## Project Structure

- `frontend/` — Website interface
- `backend/` — API and business logic
- `database/` — Database schema and seed data
- `docs/` — Project documentation
- `scripts/` — Development utilities
