# Music catalog

ข้อมูลหลักแยกตามชนิดไว้ใน `artists/`, `albums/` และ `songs/` โดยอ้างอิงกันด้วย ID

## เก็บข้อมูลที่ไหน

- `artists/*.json`: ข้อมูลเฉพาะศิลปิน เช่น ชื่อ รูป และรหัสผู้ให้บริการ; ประเทศเริ่มต้นร่วมอยู่ใน `entity-defaults.json`
- `albums/*.json`: ข้อมูล release เช่น ชื่อ ปี ภาพปก ลิงก์ผู้ให้บริการ และแหล่งอ้างอิง; `defaults.artist_ids` ระบุศิลปินหลักของไฟล์นั้น และอัลบั้มร่วมสามารถใส่ `artist_ids` ของตัวเองเพื่อทับค่าเริ่มต้น
- `songs/*.json`: ข้อมูลเฉพาะเพลง เช่น ID ชื่อเพลง `album_id`, `duration_seconds` และ YouTube `video_id`
- `index.ts`: รวมและเติมข้อมูลที่อ้างอิงให้เป็น catalog รูปแบบเดิมที่หน้าเว็บและ player ใช้

## การดึงข้อมูลร่วม

แต่ละเพลงชี้ไปยังอัลบั้มด้วย `album_id` ตัวรวมจะเติมค่าเริ่มต้นของศิลปินและอัลบั้ม แล้วดึง `artist_ids`, `source_urls` และ `cover_url` จากอัลบั้มให้เพลงอัตโนมัติ หากเพลงมีค่าของตัวเอง ค่านั้นจะใช้แทนข้อมูลจากอัลบั้ม

ค่าที่เหมือนกันทั้งไฟล์เพลงของศิลปิน เช่น `status`, `source_type`, สถานะตรวจ metadata, provider หลัก, สถานะภาพปก และ `moods` วางไว้ครั้งเดียวใน `defaults` ท้ายไฟล์เพลง ค่าที่ระบุในเพลงจะทับค่าเริ่มต้นได้เมื่อมีข้อยกเว้น

เก็บ YouTube `video_id` เป็นหลัก URL สำหรับเล่นและ URL ใน provider สร้างจาก ID ตอนรวม catalog ส่วน URL เฉพาะเพลงหรือ provider อื่นเก็บในเพลงเมื่อมีจริง จึงไม่ต้องกรอก URL เดียวกันหลายช่อง

## เพิ่มข้อมูล

1. เพิ่มหรือแก้ศิลปินใน `artists/<artist>.json`
2. เพิ่ม release ใน `albums/<artist>.json` และใส่ ID ของศิลปิน
3. เพิ่มเพลงใน `songs/<artist>.json` โดยใส่ ID เพลง ชื่อ และ `album_id`; ใส่ข้อมูลระดับเพลงเมื่อเพลงนั้นมีค่าเฉพาะ
4. เปลี่ยนค่า `defaults` เมื่อค่าเริ่มต้นของเพลงทั้งไฟล์เปลี่ยน

คง ID เดิมเมื่อแก้ metadata เพื่อไม่ให้ลิงก์หรือการอ้างอิงในหน้าเว็บเปลี่ยน

## IDs เพลงซ้ำ

ID เพลงมีรูปแบบตามลำดับในศิลปิน เช่น `dr_fuu_001` และ `three_man_down_001` การตรวจชื่อซ้ำทำภายในศิลปินเดียวกัน โดยไม่สนตัวพิมพ์เล็ก/ใหญ่หรือช่องว่างซ้ำ ชื่อซ้ำข้ามศิลปินยังคงแยกกันได้

เปิดข้อมูลรวมผ่าน `index.ts`; TypeScript ตั้งค่า `resolveJsonModule` และ `esModuleInterop` เพื่อ import JSON
